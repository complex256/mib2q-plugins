# carmqtt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust daemon for the Audi MIB2 High (MHI2Q, QNX 6.5 armv7) that reads car status from ExLAP on `127.0.0.1:25010` and publishes it to Home Assistant over MQTT with auto-discovery, behind a source abstraction that later backends (native DSI, HMI bridge) plug into.

**Architecture:** std threads + `mpsc` channels, blocking I/O, no async runtime. Source threads (supervised, restartable) emit canonical `Update`s → a router thread merges by priority and throttles → a publisher thread owns a hand-written MQTT 3.1.1 client and does HA discovery, availability and reconnect-with-snapshot. All protocol code is generic over `Read + Write` so it is unit-tested on the Mac with in-memory pipes and localhost fakes.

**Tech Stack:** Rust 2021 (host stable for tests; nightly-2026-07-21 `build-std` for the target via `qnx65-armv7-toolchain`), `serde`/`serde_json`/`toml`, mosquitto (host, integration test only), ksh (unit scripts), Python 3 (host install helper).

**Spec:** `docs/superpowers/specs/2026-09-25-carmqtt-design.md`

## Global Constraints

- Crate `carmqtt`, edition 2021, lib + bin. Must compile with host stable Rust (`cargo test`) **and** the QNX 6.5 nightly `build-std` target; no nightly-only features in the crate.
- Dependencies are exactly: `serde` (derive), `serde_json`, `toml`. No tokio/mio/async, no `getrandom`/`rand`, no crates with C code or build scripts that probe the OS. Anything else needs the controller's approval.
- Target OS is QNX 6.5 (no `pipe2`/`accept4`/`eventfd`/`SOCK_CLOEXEC`). Use only `std::net::TcpStream`/`TcpListener` with read timeouts, `std::thread`, `std::sync::mpsc`, `std::fs`.
- All timing uses `std::time::Instant`. `SystemTime` is used only for log line prefixes and the ExLAP cnonce fallback — the unit's wall clock boots at 1970 and is never stepped.
- Release profile: `panic = "abort"`, `opt-level = "s"`, `lto = true`.
- MQTT: every carmqtt publish is retained QoS 1. Topic prefix default `mib2q`, discovery prefix default `homeassistant`, VIN lower-cased in topics, signal id dots become `/` in state topics and `_` in discovery object ids.
- ExLAP: the daemon only ever sends `Protocol`, `Authenticate`, `Heartbeat`, `Subscribe`, `Get`. Never `Call` (that path controls the car's media/nav/volume).
- Offline behaviour is latest-state-only: no disk buffering, nothing queued per message while the broker is down.
- Git: repo is `mib2q-carmqtt`, identity already configured as `complex256 <me@complex256.dev>`. Every commit message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`. Never put the names excluded by the workspace CLAUDE.md in any file or commit.
- Tests must pass with `cargo test` on the host, offline, using only localhost sockets. The one test that needs mosquitto skips (with a printed notice) when mosquitto is not installed.
- Logging: use the crate macros `crate::{error, warn, info, debug, trace}` (Task 1); never `println!` outside `main.rs`.

## Review Focus

1. **rdiserver/ExLAP restarts mid-session (socket closes):** the source must mark its signals unavailable and the supervisor must reconnect and resume delivering values. Pinned by `supervisor_reconnects_after_server_drop` in Task 12.
2. **Driver switches the MMI from miles to km:** a numeric value whose unit changes must be forwarded immediately (not deadbanded against the old unit) and HA discovery must be republished with the new unit. Pinned by `unit_change_bypasses_throttle` (Task 4) and `unit_change_republishes_config` (Task 8).
3. **VIN not available at boot (ExLAP down):** the publisher must not connect with a bogus topic; with `device.vin` in config it must connect anyway. Pinned by `waits_for_vin_before_connecting` and `config_vin_override_connects_without_exlap` (Task 8).
4. **TCP reads that split an XML message or a multi-byte UTF-8 char (`°F`):** framing must reassemble correctly. Pinned by `framer_reassembles_split_utf8` (Task 10).
5. **Broker unreachable for a long time, then back:** only the latest value per signal is published on reconnect, in one burst, and memory does not grow with time offline. Pinned by `offline_updates_publish_latest_only` (Task 8).

```rust
//! Minimal leveled logger writing to a size-capped file, or stderr.
//!
//! The unit's /tmp is RAM, so the file is capped and rotated once to `<path>.1`.

use std::fmt;
use std::fs::{self, File, OpenOptions};
use std::io::Write;
use std::path::PathBuf;
use std::sync::atomic::{AtomicU8, Ordering};
use std::sync::Mutex;
use std::time::{SystemTime, UNIX_EPOCH};

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub enum Level {
    Error = 0,
    Warn = 1,
    Info = 2,
    Debug = 3,
    Trace = 4,
}

impl Level {
    pub fn parse(s: &str) -> Option<Level> {
        match s.to_ascii_lowercase().as_str() {
            "error" => Some(Level::Error),
            "warn" => Some(Level::Warn),
            "info" => Some(Level::Info),
            "debug" => Some(Level::Debug),
            "trace" => Some(Level::Trace),
            _ => None,
        }
    }

    fn tag(self) -> &'static str {
        match self {
            Level::Error => "ERROR",
            Level::Warn => "WARN",
            Level::Info => "INFO",
            Level::Debug => "DEBUG",
            Level::Trace => "TRACE",
        }
    }
}

static LEVEL: AtomicU8 = AtomicU8::new(Level::Info as u8);
static SINK: Mutex<Option<Sink>> = Mutex::new(None);

struct Sink {
    path: PathBuf,
    file: File,
    written: u64,
    cap: u64,
}

/// Send log lines to `path` (None = stderr), keeping messages at or above
/// `level`, and rotate once to `<path>.1` when the file would exceed `cap`.
pub fn init(path: Option<PathBuf>, level: Level, cap: u64) -> std::io::Result<()> {
    LEVEL.store(level as u8, Ordering::Relaxed);
    let sink = match path {
        None => None,
        Some(path) => {
            if let Some(dir) = path.parent() {
                fs::create_dir_all(dir)?;
            }
            let file = OpenOptions::new().create(true).append(true).open(&path)?;
            let written = file.metadata().map(|m| m.len()).unwrap_or(0);
            Some(Sink { path, file, written, cap })
        }
    };
    *SINK.lock().unwrap_or_else(|e| e.into_inner()) = sink;
    Ok(())
}

pub fn enabled(level: Level) -> bool {
    level as u8 <= LEVEL.load(Ordering::Relaxed)
}

pub fn write(level: Level, module: &str, args: fmt::Arguments) {
    let secs = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0);
    let line = format!("{secs} {} {module}: {args}\n", level.tag());
    let mut guard = SINK.lock().unwrap_or_else(|e| e.into_inner());
    match guard.as_mut() {
        None => {
            let _ = std::io::stderr().write_all(line.as_bytes());
        }
        Some(sink) => {
            if sink.written + line.len() as u64 > sink.cap {
                let rotated = PathBuf::from(format!("{}.1", sink.path.display()));
                let _ = fs::rename(&sink.path, &rotated);
                if let Ok(f) = OpenOptions::new()
                    .create(true)
                    .write(true)
                    .truncate(true)
                    .open(&sink.path)
                {
                    sink.file = f;
                    sink.written = 0;
                }
            }
            if sink.file.write_all(line.as_bytes()).is_ok() {
                sink.written += line.len() as u64;
            }
        }
    }
}

#[macro_export]
macro_rules! error {

    }
```

```rust
            Unit::Rpm => "rpm",
            Unit::Days => "d",
            Unit::Minutes => "min",
            Unit::Seconds => "s",
            Unit::Volt => "V",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub enum Value {
    Num { v: f64, unit: Option<Unit> },
    Bool(bool),
    /// Passed through verbatim, e.g. `"position_P"`.
    Enum(String),
    Text(String),
    Geo { lat: f64, lon: f64, heading: Option<f64>, alt: Option<f64> },
    /// The source is up but has no valid value (ExLAP `EC_xx` / `nodata`), or the source is down.
    Unavailable,
}

impl Value {
    pub fn is_available(&self) -> bool {
        !matches!(self, Value::Unavailable)
    }

    pub fn unit(&self) -> Option<Unit> {
        match self {
            Value::Num { unit, .. } => *unit,
            _ => None,
        }
    }

    /// The MQTT state payload; `None` for `Unavailable`.
    pub fn payload(&self) -> Option<String> {
        match self {
            Value::Num { v, .. } => Some(format_num(*v)),
            Value::Bool(b) => Some(if *b { "ON" } else { "OFF" }.to_string()),
            Value::Enum(s) | Value::Text(s) => Some(s.clone()),
            Value::Geo { lat, lon, heading, alt } => {
                let mut m = serde_json::Map::new();
                m.insert("latitude".into(), serde_json::json!(lat));
                m.insert("longitude".into(), serde_json::json!(lon));
                m.insert("gps_accuracy".into(), serde_json::json!(10));
                if let Some(h) = heading {
                    m.insert("heading".into(), serde_json::json!(h));
                }
                if let Some(a) = alt {
                    m.insert("altitude".into(), serde_json::json!(a));
                }
                Some(serde_json::Value::Object(m).to_string())
            }
            Value::Unavailable => None,
        }
    }
}

/// Format a number with at most 3 decimals and no trailing zeros:
/// `69760.0 -> "69760"`, `66.00000000000001 -> "66"`, `-0.02 -> "-0.02"`.
pub fn format_num(v: f64) -> String {
    let s = format!("{v:.3}");
    let s = if s.contains('.') {
        s.trim_end_matches('0').trim_end_matches('.').to_string()
    } else {
        s
    };
    if s == "-0" {
        "0".to_string()
    } else {
        s
    }
}

    pub signal: SignalId,
    pub value: Value,
    /// Source-side timestamp if the source has one (unused by v1 publishing).

    pub source: SourceId,
}
```

```rust
//! The canonical signal catalog. Router and publisher only know these ids;
//! each source maps its own data onto them.

use std::collections::HashMap;
use std::time::Duration;

use crate::value::{SignalId, Unit};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Kind {
    Sensor,
    BinarySensor,
    Tracker,
}

/// How often a signal may be forwarded.
///
/// A numeric change smaller than `deadband` is held back until `max_interval`
/// has passed since the last forward; any forward waits at least
/// `min_interval`. Bool/enum/text changes and availability changes ignore both.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Rate {
    pub enabled: bool,
    pub min_interval: Duration,
    pub deadband: f64,
    pub max_interval: Duration,
}

const MAX: Duration = Duration::from_secs(900);

impl Rate {
    pub const STATUS: Rate = Rate { enabled: true, min_interval: Duration::ZERO, deadband: 0.0, max_interval: MAX };

    pub const fn throttled(min_s: u64, deadband: f64) -> Rate {
        Rate { enabled: true, min_interval: Duration::from_secs(min_s), deadband, max_interval: MAX }
    }

    pub const fn off(min_s: u64, deadband: f64) -> Rate {
        Rate { enabled: false, min_interval: Duration::from_secs(min_s), deadband, max_interval: MAX }
    }
}

#[derive(Debug)]
pub struct SignalDef {
    pub id: &'static str,
    pub name: &'static str,
    pub kind: Kind,
    pub device_class: Option<&'static str>,
    pub state_class: Option<&'static str>,
    pub default_unit: Option<Unit>,
    pub default_rate: Rate,
    pub icon: Option<&'static str>,
}

const fn sensor(
    id: &'static str,
    name: &'static str,
    device_class: Option<&'static str>,
    state_class: Option<&'static str>,
    default_unit: Option<Unit>,
    default_rate: Rate,
    icon: Option<&'static str>,
) -> SignalDef {
    SignalDef { id, name, kind: Kind::Sensor, device_class, state_class, default_unit, default_rate, icon }
}

const fn binary(
    id: &'static str,
    name: &'static str,
    device_class: Option<&'static str>,
    default_rate: Rate,
    icon: Option<&'static str>,
) -> SignalDef {
    SignalDef { id, name, kind: Kind::BinarySensor, device_class, state_class: None, default_unit: None, default_rate, icon }
}

const M: Option<&str> = Some("measurement");

pub static CATALOG: &[SignalDef] = &[
    // --- status, enabled ---
    sensor("vin", "VIN", None, None, None, Rate::STATUS, Some("mdi:card-text")),
    sensor("odometer", "Odometer", Some("distance"), Some("total_increasing"), Some(Unit::Mi), Rate::STATUS, Some("mdi:counter")),
    sensor("fuel.level", "Fuel level", None, M, Some(Unit::Percent), Rate::throttled(60, 1.0), Some("mdi:gas-station")),
```

```rust
impl Config {
    pub fn parse(text: &str) -> Result<Config, String> {
        let cfg: Config = toml::from_str(text).map_err(|e| e.to_string())?;
        if cfg.mqtt.host.trim().is_empty() {
            return Err("mqtt.host must not be empty".into());
        }
        if Level::parse(&cfg.log.level).is_none() {
            return Err(format!("log.level '{}' is not one of error|warn|info|debug|trace", cfg.log.level));
        }
        for (id, o) in &cfg.signals {
            if catalog::lookup(id).is_none() {
                return Err(format!("unknown signal '{id}' in [signals]"));
            }
            for (name, v) in [("min_interval_s", o.min_interval_s), ("deadband", o.deadband), ("max_interval_s", o.max_interval_s)] {
                if let Some(v) = v {
                    if !(v.is_finite() && v >= 0.0) {
                        return Err(format!("signals.\"{id}\".{name} must be a non-negative number"));
                    }
                }
            }
        }
        Ok(cfg)
    }

    pub fn load(path: &Path) -> Result<Config, String> {
        let text = std::fs::read_to_string(path).map_err(|e| e.to_string())?;
        Config::parse(&text)
    }

    /// The catalog's default rates with `[signals]` overrides applied.
    pub fn effective_rates(&self) -> HashMap<SignalId, Rate> {
        let mut rates = catalog::default_rates();
        for (id, o) in &self.signals {
            let Some(def) = catalog::lookup(id) else { continue };
            let r = rates.get_mut(def.id).expect("default_rates covers the catalog");
            if let Some(e) = o.enabled {
                r.enabled = e;
            }
            if let Some(s) = o.min_interval_s {
                r.min_interval = Duration::from_secs_f64(s);
            }
            if let Some(d) = o.deadband {
                r.deadband = d;
            }
            if let Some(s) = o.max_interval_s {
                r.max_interval = Duration::from_secs_f64(s);
            }
        }
        rates
    }
}
```

```rust
//! Merges updates from all sources into one value per signal and throttles them.

use std::collections::HashMap;
use std::time::Instant;

use crate::catalog::Rate;
use crate::debug;
use crate::value::{SignalId, SourceId, Update, Value};

struct Sent {
    value: Value,
    at: Instant,
    /// The newest selected value not yet forwarded.
    pending: Option<Value>,
}

pub struct Router {
    rates: HashMap<SignalId, Rate>,
    priorities: HashMap<SourceId, i32>,
    inputs: HashMap<SignalId, Vec<(SourceId, Value)>>,
    sent: HashMap<SignalId, Sent>,
}

impl Router {
    pub fn new(rates: HashMap<SignalId, Rate>, priorities: HashMap<SourceId, i32>) -> Router {
        Router { rates, priorities, inputs: HashMap::new(), sent: HashMap::new() }
    }

    /// Highest-priority source with an available value; `Unavailable` if none.
    fn select(&self, signal: SignalId) -> Value {
        let Some(inputs) = self.inputs.get(signal) else { return Value::Unavailable };
        let mut best: Option<(i32, &Value)> = None;
        for (src, v) in inputs {
            if !v.is_available() {
                continue;
            }
            let p = self.priorities.get(src).copied().unwrap_or(0);
            if best.map(|(bp, _)| p > bp).unwrap_or(true) {
                best = Some((p, v));
            }
        }
        best.map(|(_, v)| v.clone()).unwrap_or(Value::Unavailable)
    }

    pub fn ingest(&mut self, u: Update, now: Instant) -> Option<(SignalId, Value)> {
        let Some(rate) = self.rates.get(u.signal).copied() else {
            debug!("dropping update for unknown signal {}", u.signal);
            return None;
        };
        if !rate.enabled {
            return None;
        }
        let inputs = self.inputs.entry(u.signal).or_default();
        match inputs.iter_mut().find(|(s, _)| *s == u.source) {
            Some(slot) => slot.1 = u.value,
            None => inputs.push((u.source, u.value)),
        }
        let selected = self.select(u.signal);
        let Some(sent) = self.sent.get_mut(u.signal) else {
            self.sent.insert(u.signal, Sent { value: selected.clone(), at: now, pending: None });
            return Some((u.signal, selected));
        };
        if sent.value == selected {
            sent.pending = None;
            return None;
        }
        let due = now.duration_since(sent.at) >= rate.min_interval;
        if bypasses_throttle(&sent.value, &selected) || (due && beyond_deadband(&sent.value, &selected, rate.deadband)) {
            sent.value = selected.clone();
            sent.at = now;
            sent.pending = None;
            Some((u.signal, selected))
        } else {
            sent.pending = Some(selected);
            None
        }
    }

    pub fn tick(&mut self, now: Instant) -> Vec<(SignalId, Value)> {
        let mut out = Vec::new();
        for (signal, sent) in self.sent.iter_mut() {
            let Some(pending) = sent.pending.as_ref() else { continue };
            let Some(rate) = self.rates.get(signal) else { continue };
            let since = now.duration_since(sent.at);
            if since >= rate.min_interval && (beyond_deadband(&sent.value, pending, rate.deadband) || since >= rate.max_interval) {
                let v = sent.pending.take().expect("checked above");
                sent.value = v.clone();
                sent.at = now;
                out.push((*signal, v));
            }
        }
        out
    }
}

/// Availability flips, unit changes and non-numeric changes are never held back.
fn bypasses_throttle(old: &Value, new: &Value) -> bool {
    match (old, new) {
        (Value::Num { unit: a, .. }, Value::Num { unit: b, .. }) => a != b,
        (Value::Geo { .. }, Value::Geo { .. }) => false,
        _ => true,
    }
}

fn beyond_deadband(old: &Value, new: &Value, deadband: f64) -> bool {
    match (old, new) {
        (Value::Num { v: a, .. }, Value::Num { v: b, .. }) => (b - a).abs() >= deadband && a != b,
        _ => old != new,
    }
}
```

```rust
//! MQTT 3.1.1 packet codec (sans-IO). Covers what carmqtt sends and receives,
//! plus decoding of CONNECT/SUBSCRIBE so tests can play the broker.

#[derive(Clone, Debug, PartialEq)]
pub struct Will {
    pub topic: String,
    pub payload: Vec<u8>,
    pub qos: u8,
    pub retain: bool,
}

#[derive(Clone, Debug, PartialEq)]
pub struct Connect {
    pub client_id: String,
    pub keepalive: u16,
    pub clean_session: bool,
    pub username: Option<String>,
    pub password: Option<String>,
    pub will: Option<Will>,
}

#[derive(Clone, Debug, PartialEq)]
pub struct Publish {
    pub topic: String,
    pub payload: Vec<u8>,
    pub qos: u8,
    pub retain: bool,
    pub dup: bool,
    pub pid: Option<u16>,
}

#[derive(Clone, Debug, PartialEq)]
pub enum Packet {
    Connect(Connect),
    ConnAck { session_present: bool, code: u8 },
    Publish(Publish),
    PubAck(u16),
    Subscribe { pid: u16, topics: Vec<(String, u8)> },
    SubAck { pid: u16, codes: Vec<u8> },
    PingReq,
    PingResp,
    Disconnect,
}

#[derive(Debug, PartialEq)]
pub enum DecodeError {
    Malformed(&'static str),
    Unsupported(u8),
}

pub fn encode_remaining_length(mut n: usize, out: &mut Vec<u8>) {
    loop {
        let mut b = (n % 128) as u8;
        n /= 128;
        if n > 0 {
            b |= 0x80;
        }
        out.push(b);
        if n == 0 {
            break;
        }
    }
}

/// `Ok(None)` = need more bytes; otherwise (value, bytes used).
fn decode_remaining_length(buf: &[u8]) -> Result<Option<(usize, usize)>, DecodeError> {
    let mut mult = 1usize;
    let mut value = 0usize;
    for i in 0..4 {
        let Some(&b) = buf.get(i) else { return Ok(None) };
        value += (b & 0x7F) as usize * mult;
        if b & 0x80 == 0 {
            return Ok(Some((value, i + 1)));
        }
        mult *= 128;
    }
    Err(DecodeError::Malformed("remaining length longer than 4 bytes"))
}

fn put_str(out: &mut Vec<u8>, s: &[u8]) {
    out.extend_from_slice(&(s.len() as u16).to_be_bytes());
    out.extend_from_slice(s);
}

pub fn encode(p: &Packet) -> Vec<u8> {
    let (first, body): (u8, Vec<u8>) = match p {
        Packet::Connect(c) => {
            let mut b = Vec::new();
            put_str(&mut b, b"MQTT");
            b.push(4);
            let mut flags = 0u8;
            if c.clean_session {
                flags |= 0x02;
            }
            if let Some(w) = &c.will {
                flags |= 0x04 | (w.qos << 3);
                if w.retain {
                    flags |= 0x20;
                }
            }
            if c.password.is_some() {
                flags |= 0x40;
            }
            if c.username.is_some() {
                flags |= 0x80;
            }
            b.push(flags);
            b.extend_from_slice(&c.keepalive.to_be_bytes());
            put_str(&mut b, c.client_id.as_bytes());
            if let Some(w) = &c.will {
                put_str(&mut b, w.topic.as_bytes());
                put_str(&mut b, &w.payload);
            }
            if let Some(u) = &c.username {
                put_str(&mut b, u.as_bytes());
            }
            if let Some(pw) = &c.password {
                put_str(&mut b, pw.as_bytes());
            }
            (0x10, b)
        }
        Packet::ConnAck { session_present, code } => (0x20, vec![*session_present as u8, *code]),
        Packet::Publish(p) => {
            let mut b = Vec::new();
            put_str(&mut b, p.topic.as_bytes());
            if p.qos > 0 {
                b.extend_from_slice(&p.pid.unwrap_or(0).to_be_bytes());
            }
            b.extend_from_slice(&p.payload);
            (0x30 | ((p.dup as u8) << 3) | (p.qos << 1) | p.retain as u8, b)
        }
        Packet::PubAck(pid) => (0x40, pid.to_be_bytes().to_vec()),
        Packet::Subscribe { pid, topics } => {
            let mut b = pid.to_be_bytes().to_vec();
            for (t, q) in topics {
                put_str(&mut b, t.as_bytes());
                b.push(*q);
            }
            (0x82, b)
        }
        Packet::SubAck { pid, codes } => {
            let mut b = pid.to_be_bytes().to_vec();
            b.extend_from_slice(codes);
            (0x90, b)
        }
        Packet::PingReq => (0xC0, Vec::new()),
        Packet::PingResp => (0xD0, Vec::new()),
        Packet::Disconnect => (0xE0, Vec::new()),
    };
    let mut out = vec![first];
    encode_remaining_length(body.len(), &mut out);
    out.extend_from_slice(&body);
    out
}

struct Rd<'a> {
    b: &'a [u8],
    i: usize,
}

impl<'a> Rd<'a> {
    fn u8(&mut self) -> Result<u8, DecodeError> {
        let v = *self.b.get(self.i).ok_or(DecodeError::Malformed("short packet"))?;
        self.i += 1;
        Ok(v)
    }
    fn u16(&mut self) -> Result<u16, DecodeError> {
        Ok(u16::from_be_bytes([self.u8()?, self.u8()?]))
    }
    fn bytes(&mut self) -> Result<Vec<u8>, DecodeError> {
        let n = self.u16()? as usize;
        let s = self.b.get(self.i..self.i + n).ok_or(DecodeError::Malformed("short string"))?;
        self.i += n;
        Ok(s.to_vec())
    }
    fn string(&mut self) -> Result<String, DecodeError> {
        String::from_utf8(self.bytes()?).map_err(|_| DecodeError::Malformed("string is not utf-8"))
    }
    fn rest(&mut self) -> Vec<u8> {
        let r = self.b[self.i..].to_vec();
        self.i = self.b.len();
        r
    }
    fn done(&self) -> bool {
        self.i >= self.b.len()
    }
}

pub fn decode(buf: &[u8]) -> Result<Option<(Packet, usize)>, DecodeError> {
    let Some(&first) = buf.first() else { return Ok(None) };
    let Some((len, hl)) = decode_remaining_length(&buf[1..])? else { return Ok(None) };
    let total = 1 + hl + len;
    if buf.len() < total {
        return Ok(None);
    }
    let mut r = Rd { b: &buf[1 + hl..total], i: 0 };
    let pkt = match first >> 4 {
        1 => {
            if r.bytes()? != b"MQTT" {
                return Err(DecodeError::Malformed("protocol name"));
            }
            let _level = r.u8()?;
            let flags = r.u8()?;
            let keepalive = r.u16()?;
            let client_id = r.string()?;
            let will = if flags & 0x04 != 0 {
                let topic = r.string()?;
                let payload = r.bytes()?;
                Some(Will { topic, payload, qos: (flags >> 3) & 3, retain: flags & 0x20 != 0 })
            } else {
                None
            };
            let username = if flags & 0x80 != 0 { Some(r.string()?) } else { None };
            let password = if flags & 0x40 != 0 { Some(r.string()?) } else { None };
            Packet::Connect(Connect { client_id, keepalive, clean_session: flags & 0x02 != 0, username, password, will })
        }
        2 => {
            let session_present = r.u8()? & 1 == 1;
            let code = r.u8()?;
            Packet::ConnAck { session_present, code }
        }
        3 => {
            let qos = (first >> 1) & 3;
            let topic = r.string()?;
            let pid = if qos > 0 { Some(r.u16()?) } else { None };
            Packet::Publish(Publish { topic, payload: r.rest(), qos, retain: first & 1 == 1, dup: first & 8 != 0, pid })
        }
        4 => Packet::PubAck(r.u16()?),
        8 => {
            let pid = r.u16()?;
            let mut topics = Vec::new();
            while !r.done() {
                let t = r.string()?;
                let q = r.u8()?;
                topics.push((t, q));
            }
            Packet::Subscribe { pid, topics }
        }
        9 => {
            let pid = r.u16()?;
            Packet::SubAck { pid, codes: r.rest() }
        }
        12 => Packet::PingReq,
        13 => Packet::PingResp,
        14 => Packet::Disconnect,
        t => return Err(DecodeError::Unsupported(t)),
    };
    Ok(Some((pkt, total)))
}
```

```rust
//! Helpers shared by unit and integration tests: an in-memory duplex pipe
//! (and, from Task 13, a fake ExLAP server). Small enough to always compile.

use std::collections::VecDeque;
use std::io::{self, Read, Write};
use std::sync::{Arc, Mutex};

use crate::mqtt::codec::{self, Packet};

#[derive(Default)]
struct Pipe {
    inbound: VecDeque<u8>,
    outbound: Vec<u8>,
    closed: bool,
}

/// The code-under-test side. Reads return `WouldBlock` when nothing is queued,
/// like a socket with a read timeout, and `Ok(0)` once the handle closes it.
#[derive(Clone)]
pub struct MockIo(Arc<Mutex<Pipe>>);

/// The test's side of the pipe.
#[derive(Clone)]
pub struct MockHandle(Arc<Mutex<Pipe>>);

pub fn mock_pair() -> (MockIo, MockHandle) {
    let p = Arc::new(Mutex::new(Pipe::default()));
    (MockIo(p.clone()), MockHandle(p))
}

impl Read for MockIo {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        let mut p = self.0.lock().unwrap();
        if p.inbound.is_empty() {
            return if p.closed { Ok(0) } else { Err(io::ErrorKind::WouldBlock.into()) };
        }
        let n = buf.len().min(p.inbound.len());
        for (slot, b) in buf.iter_mut().zip(p.inbound.drain(..n)) {
            *slot = b;
        }
        Ok(n)
    }
}

impl Write for MockIo {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        let mut p = self.0.lock().unwrap();
        if p.closed {
            return Err(io::ErrorKind::BrokenPipe.into());
        }
        p.outbound.extend_from_slice(buf);
        Ok(buf.len())
    }

    fn flush(&mut self) -> io::Result<()> {
        Ok(())
    }

        self.0.lock().unwrap().inbound.extend(bytes.iter().copied());
    }

    pub fn take_written(&self) -> Vec<u8> {
        std::mem::take(&mut self.0.lock().unwrap().outbound)
    }

    pub fn close(&self) {
        self.0.lock().unwrap().closed = true;
    }
}

/// Decode every complete MQTT packet in `bytes`. Panics on malformed input.
pub fn mqtt_packets(mut bytes: &[u8]) -> Vec<Packet> {
    let mut out = Vec::new();
    while let Some((p, n)) = codec::decode(bytes).expect("valid mqtt") {
        out.push(p);
        bytes = &bytes[n..];
    }
    out
}
```

```rust
//! Blocking MQTT 3.1.1 client over any `Read + Write` with short read timeouts.

use std::fmt;
use std::io::{self, Read, Write};
use std::time::{Duration, Instant};

use super::codec::{self, Connect, Packet, Publish, Will};

#[derive(Clone, Debug)]
pub struct Options {
    pub client_id: String,
    pub username: Option<String>,
    pub password: Option<String>,
    pub keepalive: Duration,
    pub will: Option<Will>,
}

#[derive(Debug)]
pub enum MqttError {
    Io(io::Error),
    Refused(u8),
    Protocol(String),
    Timeout,
}

impl From<io::Error> for MqttError {
    fn from(e: io::Error) -> Self {
        MqttError::Io(e)
    }
}

impl fmt::Display for MqttError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            MqttError::Io(e) => write!(f, "i/o: {e}"),
            MqttError::Refused(c) => write!(f, "connection refused by broker (code {c})"),
            MqttError::Protocol(s) => write!(f, "protocol: {s}"),
            MqttError::Timeout => write!(f, "timed out"),
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub enum Incoming {
    Publish { topic: String, payload: Vec<u8> },
}

pub struct Client<S: Read + Write> {
    io: S,
    buf: Vec<u8>,
    next_pid: u16,
    keepalive: Duration,
    last_tx: Instant,
    ping_sent: Option<Instant>,
}

fn is_would_block(e: &io::Error) -> bool {
    matches!(e.kind(), io::ErrorKind::WouldBlock | io::ErrorKind::TimedOut | io::ErrorKind::Interrupted)
}

impl<S: Read + Write> Client<S> {
    /// Send CONNECT and wait up to `timeout` for CONNACK.
    pub fn connect(io: S, opts: &Options, timeout: Duration) -> Result<Self, MqttError> {
        let mut c = Client { io, buf: Vec::new(), next_pid: 1, keepalive: opts.keepalive, last_tx: Instant::now(), ping_sent: None };
        c.send(&Packet::Connect(Connect {
            client_id: opts.client_id.clone(),
            keepalive: opts.keepalive.as_secs().min(u16::MAX as u64) as u16,
            clean_session: true,
            username: opts.username.clone(),
            password: opts.password.clone(),
            will: opts.will.clone(),
        }))?;
        let deadline = Instant::now() + timeout;
        loop {
            if let Some(p) = c.next_packet()? {
                return match p {
                    Packet::ConnAck { code: 0, .. } => Ok(c),
                    Packet::ConnAck { code, .. } => Err(MqttError::Refused(code)),
                    other => Err(MqttError::Protocol(format!("expected CONNACK, got {other:?}"))),
                };
            }
            if Instant::now() >= deadline {
                return Err(MqttError::Timeout);
            }
            if !c.fill()? {
                std::thread::sleep(Duration::from_millis(5));
            }
        }
    }

    fn send(&mut self, p: &Packet) -> Result<(), MqttError> {
        self.io.write_all(&codec::encode(p))?;
        self.io.flush()?;
        self.last_tx = Instant::now();
        Ok(())
    }

    /// One read. `Ok(true)` if bytes arrived, `Ok(false)` if none were available.
    fn fill(&mut self) -> Result<bool, MqttError> {
        let mut tmp = [0u8; 4096];
        match self.io.read(&mut tmp) {
            Ok(0) => Err(MqttError::Io(io::Error::new(io::ErrorKind::UnexpectedEof, "broker closed the connection"))),
            Ok(n) => {
                self.buf.extend_from_slice(&tmp[..n]);
                Ok(true)
            }
            Err(e) if is_would_block(&e) => Ok(false),
            Err(e) => Err(e.into()),
        }
    }

    fn next_packet(&mut self) -> Result<Option<Packet>, MqttError> {
        match codec::decode(&self.buf) {
            Ok(Some((p, n))) => {
                self.buf.drain(..n);
                Ok(Some(p))
            }
            Ok(None) => Ok(None),
            Err(e) => Err(MqttError::Protocol(format!("{e:?}"))),
        }
    }

    fn pid(&mut self) -> u16 {
        let p = self.next_pid;
        self.next_pid = if p == u16::MAX { 1 } else { p + 1 };
        p
    }

    pub fn publish(&mut self, topic: &str, payload: &[u8], qos: u8, retain: bool) -> Result<(), MqttError> {
        let pid = if qos > 0 { Some(self.pid()) } else { None };
        self.send(&Packet::Publish(Publish { topic: topic.to_string(), payload: payload.to_vec(), qos, retain, dup: false, pid }))
    }

    pub fn subscribe(&mut self, topic: &str, qos: u8) -> Result<(), MqttError> {
        let pid = self.pid();
        self.send(&Packet::Subscribe { pid, topics: vec![(topic.to_string(), qos)] })
    }

    /// Read whatever is available, answer/consume control packets, keep the
    /// connection alive, and return application messages.
    pub fn poll(&mut self, now: Instant) -> Result<Vec<Incoming>, MqttError> {
        while self.fill()? {}
        let mut out = Vec::new();
        while let Some(p) = self.next_packet()? {
            match p {
                Packet::PingResp => self.ping_sent = None,
                Packet::Publish(p) => {
                    if let (1, Some(pid)) = (p.qos, p.pid) {
                        self.send(&Packet::PubAck(pid))?;
                    }
                    out.push(Incoming::Publish { topic: p.topic, payload: p.payload });
                }
                Packet::PubAck(_) | Packet::SubAck { .. } => {}
                other => return Err(MqttError::Protocol(format!("unexpected {other:?}"))),
            }
        }
        match self.ping_sent {
            Some(t) if now.duration_since(t) > self.keepalive => return Err(MqttError::Timeout),
            None if !self.keepalive.is_zero() && now.duration_since(self.last_tx) >= self.keepalive / 2 => {
                self.send(&Packet::PingReq)?;
                self.ping_sent = Some(now);
            }
            _ => {}
        }
        Ok(out)
    }

    pub fn disconnect(mut self) -> Result<(), MqttError> {
        self.send(&Packet::Disconnect)
    }
}
```

```rust
//! Exponential backoff for reconnect loops.

use std::time::Duration;

pub struct Backoff {
    min: Duration,
    max: Duration,
    cur: Duration,
}

impl Backoff {
    pub fn new(min: Duration, max: Duration) -> Backoff {
        Backoff { min, max, cur: min }
    }

    /// The delay to wait now; the following call returns twice as much, up to `max`.
    pub fn next(&mut self) -> Duration {
        let d = self.cur;
        self.cur = (self.cur * 2).min(self.max);
        d
    }

    pub fn reset(&mut self) {
        self.cur = self.min;
    }
}

        let mut b = Backoff::new(Duration::from_secs(1), Duration::from_secs(60));
        let got: Vec<u64> = (0..8).map(|_| b.next().as_secs()).collect();
        assert_eq!(got, vec![1, 2, 4, 8, 16, 32, 60, 60]);
        b.reset();
        assert_eq!(b.next(), Duration::from_secs(1));
```

```rust
impl Connector for TcpConnector {

    fn connect(&mut self) -> io::Result<TcpStream> {
        let mut last = io::Error::new(io::ErrorKind::NotFound, "host resolved to no addresses");
        for addr in (self.host.as_str(), self.port).to_socket_addrs()? {
            match TcpStream::connect_timeout(&addr, Duration::from_secs(5)) {
                Ok(s) => {
                    s.set_read_timeout(Some(Duration::from_millis(50)))?;
                    s.set_nodelay(true)?;
                    return Ok(s);
                }
                Err(e) => last = e,
            }
        }
        Err(last)
    }

pub struct PublisherConfig {
    pub topic_prefix: String,
    pub discovery_prefix: String,
    pub device: DeviceInfo,
    pub vin_override: Option<String>,
    pub client_id: String,
    pub username: Option<String>,
    pub password: Option<String>,

struct Announced {
    unit: Option<Unit>,
    available: bool,
}

pub struct Publisher<C: Connector> {
    cfg: PublisherConfig,
    conn: C,
    client: Option<Client<C::Io>>,
    topics: Option<Topics>,
    mirror: BTreeMap<SignalId, Value>,
    announced: HashMap<SignalId, Announced>,
    backoff: Backoff,
    next_attempt: Instant,
}

impl<C: Connector> Publisher<C> {
    pub fn new(cfg: PublisherConfig, conn: C) -> Self {
        Publisher {
            cfg,
            conn,
            client: None,
            topics: None,
            mirror: BTreeMap::new(),
            announced: HashMap::new(),
            backoff: Backoff::new(Duration::from_secs(1), Duration::from_secs(60)),
            next_attempt: Instant::now(),
        }
    }

    pub fn is_connected(&self) -> bool {
        self.client.is_some()
    }

    pub fn vin(&self) -> Option<String> {
        if let Some(v) = &self.cfg.vin_override {
            return Some(v.clone());
        }
        match self.mirror.get("vin") {
            Some(Value::Text(v)) if !v.is_empty() => Some(v.clone()),
            _ => None,
        }
    }

    pub fn handle(&mut self, signal: SignalId, value: Value) {
        self.mirror.insert(signal, value);
        if self.client.is_some() {
            if let Err(e) = self.emit(signal) {
                self.drop_connection(e);
            }
        }
    }

    pub fn step(&mut self, now: Instant) {
        if let Some(client) = self.client.as_mut() {
            match client.poll(now) {
                Ok(incoming) => {
                    let ha_status = self.topics.as_ref().map(|t| t.ha_status());
                    let ha_online = incoming.iter().any(|Incoming::Publish { topic, payload }| {
                        Some(topic) == ha_status.as_ref() && payload.as_slice() == b"online"
                    });
                    if ha_online {
                        info!("home assistant came online; re-announcing");
                        self.announced.clear();
                        if let Err(e) = self.emit_all() {
                            self.drop_connection(e);
                        }
                    }
                }
                Err(e) => self.drop_connection(e),
            }
            return;
        }
        if now < self.next_attempt {
            return;
        }
        let Some(vin) = self.vin() else { return };
        if let Err(e) = self.try_connect(&vin) {
            self.client = None;
            let d = self.backoff.next();
            warn!("mqtt connect failed: {e}; retrying in {}s", d.as_secs());
            self.next_attempt = now + d;
        }
    }

    fn try_connect(&mut self, vin: &str) -> Result<(), MqttError> {
        let topics = match &self.topics {
            Some(t) => t.clone(),
            None => {
                let t = Topics::new(&self.cfg.topic_prefix, &self.cfg.discovery_prefix, vin);
                self.topics = Some(t.clone());
                t
            }
        };
        let io = self.conn.connect()?;
        let opts = Options {
            client_id: self.cfg.client_id.clone(),
            username: self.cfg.username.clone(),
            password: self.cfg.password.clone(),
            keepalive: self.cfg.keepalive,
            will: Some(Will { topic: topics.status(), payload: b"offline".to_vec(), qos: 1, retain: true }),
        };
        let mut client = Client::connect(io, &opts, Duration::from_secs(10))?;
        client.subscribe(&topics.ha_status(), 0)?;
        client.publish(&topics.status(), b"online", 1, true)?;
        self.client = Some(client);
        self.announced.clear();
        info!("mqtt connected; publishing {} signals", self.mirror.len());
        self.emit_all()?;
        self.backoff.reset();
        Ok(())
    }

    fn emit_all(&mut self) -> Result<(), MqttError> {
        let signals: Vec<SignalId> = self.mirror.keys().copied().collect();
        for s in signals {
            self.emit(s)?;
        }
        Ok(())
    }

    fn emit(&mut self, signal: SignalId) -> Result<(), MqttError> {
        let (Some(client), Some(topics)) = (self.client.as_mut(), self.topics.as_ref()) else { return Ok(()) };
        let Some(def) = catalog::lookup(signal) else {
            debug!("no catalog entry for {signal}; not publishing");
            return Ok(());
        };
        let Some(value) = self.mirror.get(signal) else { return Ok(()) };
        let available = value.is_available();
        let prev = self.announced.get(signal);
        let unit = if available {
            value.unit().or(def.default_unit)
        } else {
            prev.and_then(|a| a.unit).or(def.default_unit)
        };
        if prev.map(|a| a.unit != unit).unwrap_or(true) {
            let payload = config_payload(topics, def, unit, &self.cfg.device);
            client.publish(&topics.config(def), payload.as_bytes(), 1, true)?;
        }
        if prev.map(|a| a.available != available).unwrap_or(true) {
            let p: &[u8] = if available { b"online" } else { b"offline" };
            client.publish(&topics.avail(signal), p, 1, true)?;
        }
        if let Some(p) = value.payload() {
            client.publish(&topics.value_topic(def), p.as_bytes(), 1, true)?;
        }
        self.announced.insert(signal, Announced { unit, available });
        Ok(())
    }

    fn drop_connection(&mut self, e: MqttError) {
        let d = self.backoff.next();
        warn!("mqtt connection lost: {e}; reconnecting in {}s", d.as_secs());
        self.client = None;
        self.next_attempt = Instant::now() + d;
    }

    /// Publish `offline` and disconnect cleanly, if connected.
    pub fn shutdown(&mut self) {
        if let (Some(mut c), Some(t)) = (self.client.take(), self.topics.as_ref()) {
            let _ = c.publish(&t.status(), b"offline", 1, true);
            let _ = c.disconnect();
        }
    }

    /// Run until `rx` disconnects (the router stopped), then shut down.
    pub fn run(mut self, rx: Receiver<(SignalId, Value)>) {
        loop {
            match rx.recv_timeout(Duration::from_millis(100)) {
                Ok((s, v)) => {
                    self.handle(s, v);
                    while let Ok((s, v)) = rx.try_recv() {
                        self.handle(s, v);
                    }
                }
                Err(RecvTimeoutError::Timeout) => {}
                Err(RecvTimeoutError::Disconnected) => break,
            }
            self.step(Instant::now());
        }
        self.shutdown();
    }
}
```

```rust
pub fn sha256(data: &[u8]) -> [u8; 32] {
    let mut h: [u32; 8] = [
        0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19,
    ];
    let mut msg = data.to_vec();
    let bit_len = (data.len() as u64).wrapping_mul(8);
    msg.push(0x80);
    while msg.len() % 64 != 56 {
        msg.push(0);
    }
    msg.extend_from_slice(&bit_len.to_be_bytes());
    for chunk in msg.chunks_exact(64) {
        let mut w = [0u32; 64];
        for (i, word) in chunk.chunks_exact(4).enumerate() {
            w[i] = u32::from_be_bytes([word[0], word[1], word[2], word[3]]);
        }
        for i in 16..64 {
            let s0 = w[i - 15].rotate_right(7) ^ w[i - 15].rotate_right(18) ^ (w[i - 15] >> 3);
            let s1 = w[i - 2].rotate_right(17) ^ w[i - 2].rotate_right(19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16].wrapping_add(s0).wrapping_add(w[i - 7]).wrapping_add(s1);
        }
        let [mut a, mut b, mut c, mut d, mut e, mut f, mut g, mut hh] = h;
        for i in 0..64 {
            let s1 = e.rotate_right(6) ^ e.rotate_right(11) ^ e.rotate_right(25);
            let ch = (e & f) ^ (!e & g);
            let t1 = hh.wrapping_add(s1).wrapping_add(ch).wrapping_add(K[i]).wrapping_add(w[i]);
            let s0 = a.rotate_right(2) ^ a.rotate_right(13) ^ a.rotate_right(22);
            let maj = (a & b) ^ (a & c) ^ (b & c);
            let t2 = s0.wrapping_add(maj);
            hh = g;
            g = f;
            f = e;
            e = d.wrapping_add(t1);
            d = c;
            c = b;
            b = a;
            a = t1.wrapping_add(t2);
        }
        for (x, v) in h.iter_mut().zip([a, b, c, d, e, f, g, hh]) {
            *x = x.wrapping_add(v);
        }
    }
    let mut out = [0u8; 32];
    for (i, v) in h.iter().enumerate() {
        out[i * 4..i * 4 + 4].copy_from_slice(&v.to_be_bytes());
    }
    out
}

const B64: &[u8; 64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";

pub fn b64(data: &[u8]) -> String {
    let mut out = String::with_capacity((data.len() + 2) / 3 * 4);
    for chunk in data.chunks(3) {
        let n = (chunk[0] as u32) << 16
            | (*chunk.get(1).unwrap_or(&0) as u32) << 8
            | *chunk.get(2).unwrap_or(&0) as u32;
        out.push(B64[(n >> 18) as usize & 63] as char);
        out.push(B64[(n >> 12) as usize & 63] as char);
        out.push(if chunk.len() > 1 { B64[(n >> 6) as usize & 63] as char } else { '=' });
        out.push(if chunk.len() > 2 { B64[n as usize & 63] as char } else { '=' });
    }
    out
}

/// The server only hashes the first 44 characters of each field (the
/// passwords are 45 characters long).
fn t44(s: &str) -> &str {
    match s.char_indices().nth(44) {
        Some((i, _)) => &s[..i],
        None => s,
    }
}

pub fn digest(user: &str, pass: &str, nonce: &str, cnonce: &str) -> String {
    let input = format!("{}:{}:{}:{}", t44(user), t44(pass), t44(nonce), t44(cnonce));
    b64(&sha256(input.as_bytes()))
}

pub fn cnonce() -> String {
    let mut buf = [0u8; 16];
    if File::open("/dev/urandom").and_then(|mut f| f.read_exact(&mut buf)).is_err() {
        let t = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_nanos()).unwrap_or(0);
        buf = t.to_le_bytes();
    }
    b64(&buf)
}
```

```rust
//! Just enough XML for ExLAP: split the TCP stream into top-level messages
//! and scan their start tags. No DOM, no dependencies.

#[derive(Clone, Debug, PartialEq)]
pub struct Element {
    pub tag: String,
    pub attrs: Vec<(String, String)>,
}

impl Element {
    pub fn attr(&self, key: &str) -> Option<&str> {
        self.attrs.iter().find(|(k, _)| k == key).map(|(_, v)| v.as_str())
    }
}

#[derive(Clone, Debug, PartialEq)]
pub enum Msg {
    /// `<Status><Init/></Status>`, sent by the server right after connect.
    Init,
    Status(Vec<Element>),
    Rsp { id: Option<u32>, status: Option<String>, children: Vec<Element> },
    Dat { url: String, children: Vec<Element> },
    Other(String),
}

#[derive(Default)]
pub struct Framer {
    buf: Vec<u8>,
}

fn find(hay: &[u8], needle: &[u8]) -> Option<usize> {
    hay.windows(needle.len()).position(|w| w == needle)
}

impl Framer {
    pub fn push(&mut self, bytes: &[u8]) -> Vec<String> {
        self.buf.extend_from_slice(bytes);
        let mut out = Vec::new();
        loop {
            let Some(start) = self.buf.iter().position(|b| !b.is_ascii_whitespace()) else {
                self.buf.clear();
                break;
            };
            if self.buf[start] != b'<' {
                match self.buf[start..].iter().position(|&b| b == b'<') {
                    Some(i) => {
                        self.buf.drain(..start + i);
                        continue;
                    }
                    None => {
                        self.buf.clear();
                        break;
                    }
                }
            }
            let rest = &self.buf[start..];
            let Some(gt) = rest.iter().position(|&b| b == b'>') else { break };
            if rest.starts_with(b"<?") || rest.starts_with(b"<!") || rest.starts_with(b"</") {
                self.buf.drain(..start + gt + 1);
                continue;
            }
            let name_end = rest[1..]
                .iter()
                .position(|&b| b.is_ascii_whitespace() || b == b'>' || b == b'/')
                .map(|i| i + 1)
                .unwrap_or(gt);
            let end = if rest[gt - 1] == b'/' {
                gt + 1
            } else {
                let mut close = b"</".to_vec();
                close.extend_from_slice(&rest[1..name_end]);
                close.push(b'>');
                match find(rest, &close) {
                    Some(i) => i + close.len(),
                    None => break,
                }
            };
            out.push(String::from_utf8_lossy(&rest[..end]).into_owned());
            self.buf.drain(..start + end);
        }
        out
    }
}

pub fn unescape(s: &str) -> String {
    s.replace("&lt;", "<")
        .replace("&gt;", ">")
        .replace("&quot;", "\"")
        .replace("&apos;", "'")
        .replace("&amp;", "&")
}

pub fn escape_attr(s: &str) -> String {
    s.replace('&', "&amp;").replace('<', "&lt;").replace('>', "&gt;").replace('"', "&quot;")
}

fn parse_attrs(s: &str) -> Vec<(String, String)> {
    let mut out = Vec::new();
    let mut rest = s;
    loop {
        rest = rest.trim_start();
        let Some(eq) = rest.find('=') else { break };
        let key = rest[..eq].trim().to_string();
        let after = rest[eq + 1..].trim_start();
        let Some(q) = after.chars().next() else { break };
        if q != '"' && q != '\'' {
            break;
        }
        let Some(close) = after[1..].find(q) else { break };
        out.push((key, unescape(&after[1..1 + close])));
        rest = &after[close + 2..];
    }
    out
}

/// Every start or empty-element tag in `s`, in order.
pub fn start_tags(s: &str) -> Vec<Element> {
    let mut out = Vec::new();
    let mut i = 0;
    while let Some(off) = s[i..].find('<') {
        let at = i + off;
        let Some(gt_off) = s[at..].find('>') else { break };
        let gt = at + gt_off;
        let inner = &s[at + 1..gt];
        i = gt + 1;
        if inner.starts_with('/') || inner.starts_with('?') || inner.starts_with('!') {
            continue;
        }
        let inner = inner.strip_suffix('/').unwrap_or(inner);
        let name_len = inner.find(|c: char| c.is_ascii_whitespace()).unwrap_or(inner.len());
        out.push(Element { tag: inner[..name_len].to_string(), attrs: parse_attrs(&inner[name_len..]) });
    }
    out
}

pub fn parse(msg: &str) -> Msg {
    let tags = start_tags(msg);
    let Some(first) = tags.first() else { return Msg::Other(msg.to_string()) };
    match first.tag.as_str() {
        "Status" if tags.iter().any(|t| t.tag == "Init") => Msg::Init,
        "Status" => Msg::Status(tags[1..].to_vec()),
        "Rsp" => Msg::Rsp {
            id: first.attr("id").and_then(|v| v.parse().ok()),
            status: first.attr("status").map(str::to_string),
            children: tags[1..].to_vec(),
        },
        "Dat" => Msg::Dat { url: first.attr("url").unwrap_or_default().to_string(), children: tags[1..].to_vec() },
        _ => Msg::Other(msg.to_string()),
    }
}
```

```rust
#[derive(Default)]
pub struct Decoder {
    heading: Option<f64>,
    alt: Option<f64>,
    geo: Option<(f64, f64)>,
}

impl Decoder {
    pub fn decode(&mut self, url: &str, fields: &[Element]) -> Vec<(SignalId, Value)> {
        let invalid = field(fields, "state")
            .and_then(|e| e.attr("val"))
            .map(|v| v != "valid")
            .unwrap_or(false);
        let mut out = Vec::new();
        for m in MAP.iter().filter(|m| m.url == url) {
            match m.conv {
                Conv::GeoLat => out.push((m.signal, self.geo_position(fields))),
                Conv::GeoLon => {}
                Conv::GeoHeading => {
                    self.heading = num(field(fields, m.field));
                    if let Some(g) = self.geo_value() {
                        out.push((m.signal, g));
                    }
                }
                Conv::GeoAltitude => {
                    self.alt = num(field(fields, m.field));
                    if let Some(g) = self.geo_value() {
                        out.push((m.signal, g));
                    }
                }
                _ => {
                    let Some(e) = field(fields, m.field) else { continue };
                    let value = if invalid { Value::Unavailable } else { convert(m, e, fields) };
                    out.push((m.signal, value));
                }
            }
        }
        out
    }

    fn geo_position(&mut self, fields: &[Element]) -> Value {
        match (num(field(fields, "Latitude")), num(field(fields, "Longitude"))) {
            (Some(lat), Some(lon)) => {
                self.geo = Some((lat, lon));
                self.geo_value().expect("just set")
            }
            _ => {
                self.geo = None;
                Value::Unavailable
            }
        }
    }

    fn geo_value(&self) -> Option<Value> {
        self.geo.map(|(lat, lon)| Value::Geo { lat, lon, heading: self.heading, alt: self.alt })
    }
}

fn convert(m: &FieldMap, e: &Element, fields: &[Element]) -> Value {
    let Some(raw) = val(e) else { return Value::Unavailable };
    match m.conv {
        Conv::Num | Conv::Scale(_) => {
            let Ok(v) = raw.parse::<f64>() else {
                warn!("exlap {}.{}: not a number: {raw:?}", m.url, m.field);
                return Value::Unavailable;
            };
            let v = if let Conv::Scale(k) = m.conv { v * k } else { v };
            let unit = match m.unit_field.and_then(|uf| field(fields, uf)).and_then(val) {
                Some(u) => {
                    let parsed = unit_from_exlap(u);
                    if parsed.is_none() {
                        warn!("exlap {}.{}: unknown unit {u:?}", m.url, m.field);
                    }
                    parsed
                }
                None => m.unit,
            };
            Value::Num { v, unit }
        }
        Conv::Bool => match raw {
            "true" => Value::Bool(true),
            "false" => Value::Bool(false),
            other => Value::Enum(other.to_string()),
        },
        Conv::Enum => Value::Enum(raw.to_string()),
        Conv::Text => Value::Text(raw.to_string()),
        Conv::GeoLat | Conv::GeoLon | Conv::GeoHeading | Conv::GeoAltitude => Value::Unavailable,
    }
}
```

```rust
//! Data sources. Each maps its own protocol onto catalog signals and runs on
//! its own supervised thread.

pub mod exlap;

use std::fmt;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::mpsc::Sender;
use std::sync::Arc;
use std::thread::{self, JoinHandle};
use std::time::{Duration, Instant};

use crate::backoff::Backoff;
use crate::value::{SignalId, SourceId, Update, Value};
use crate::warn;

pub type StopFlag = Arc<AtomicBool>;

pub fn stop_flag() -> StopFlag {
    Arc::new(AtomicBool::new(false))
}

pub fn stopped(stop: &StopFlag) -> bool {
    stop.load(Ordering::Relaxed)
}

#[derive(Clone, Debug, PartialEq)]
pub struct SourceError(pub String);

impl fmt::Display for SourceError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        f.write_str(&self.0)
    }
}

pub trait Source: Send {
    fn id(&self) -> SourceId;
    /// Every catalog signal this source can emit (after config filtering).
    fn provides(&self) -> &[SignalId];
    /// Block until `stop` is set or the source fails. Owns its own
    /// connect/auth loop; returning `Err` makes the supervisor retry.
    fn run(&mut self, tx: &Sender<Update>, stop: &StopFlag) -> Result<(), SourceError>;
}

/// Tell the router this source no longer has values for `signals`.
pub fn mark_unavailable(tx: &Sender<Update>, source: SourceId, signals: &[SignalId]) {
    for &signal in signals {
        let _ = tx.send(Update { signal, value: Value::Unavailable, ts: None, source });
    }
}

pub fn supervise(src: Box<dyn Source>, tx: Sender<Update>, stop: StopFlag) -> JoinHandle<()> {
    supervise_with(src, tx, stop, Duration::from_secs(1), Duration::from_secs(60))
}

pub fn supervise_with(mut src: Box<dyn Source>, tx: Sender<Update>, stop: StopFlag, min: Duration, max: Duration) -> JoinHandle<()> {
    thread::Builder::new()
        .name(format!("src-{}", src.id()))
        .spawn(move || {
            let mut backoff = Backoff::new(min, max);
            while !stopped(&stop) {
                let started = Instant::now();
                match src.run(&tx, &stop) {
                    Ok(()) if stopped(&stop) => break,
                    Ok(()) => warn!("source {} returned; restarting", src.id()),
                    Err(e) => warn!("source {} failed: {e}", src.id()),
                }
                if started.elapsed() >= max {
                    backoff.reset();
                }
                let until = Instant::now() + backoff.next();
                while !stopped(&stop) && Instant::now() < until {
                    thread::sleep(Duration::from_millis(20));
                }
            }
        })
        .expect("spawn source thread")
}
```

```rust
    }

pub struct Session<S: Read + Write> {
    io: S,
    framer: Framer,
    queue: VecDeque<String>,
    next_id: u32,
}

impl<S: Read + Write> Session<S> {
    pub fn new(io: S) -> Self {
        Session { io, framer: Framer::default(), queue: VecDeque::new(), next_id: 1 }
    }

    pub fn send(&mut self, body: &str) -> Result<u32, ExlapError> {
        let id = self.next_id;
        self.next_id += 1;
        self.io.write_all(format!("<Req id=\"{id}\">{body}</Req>").as_bytes())?;
        self.io.flush()?;
        Ok(id)
    }

    /// The next message, or `None` if none arrived before `deadline`.
    pub fn recv(&mut self, deadline: Instant) -> Result<Option<Msg>, ExlapError> {
        loop {
            if let Some(m) = self.queue.pop_front() {
                return Ok(Some(parse(&m)));
            }
            if Instant::now() >= deadline {
                return Ok(None);
            }
            let mut buf = [0u8; 8192];
            match self.io.read(&mut buf) {
                Ok(0) => return Err(ExlapError::Closed),
                Ok(n) => {
                    let msgs = self.framer.push(&buf[..n]);
                    self.queue.extend(msgs);
                }
                Err(e) if e.kind() == io::ErrorKind::WouldBlock => std::thread::sleep(Duration::from_millis(5)),
                Err(e) if matches!(e.kind(), io::ErrorKind::TimedOut | io::ErrorKind::Interrupted) => {}
                Err(e) => return Err(e.into()),
            }
        }
    }

    fn wait_rsp(&mut self, id: u32, deadline: Instant, what: &'static str) -> Result<(Option<String>, Vec<Element>), ExlapError> {
        loop {
            match self.recv(deadline)? {
                Some(Msg::Rsp { id: Some(i), status, children }) if i == id => return Ok((status, children)),
                Some(_) => continue,
                None => return Err(ExlapError::Timeout(what)),
            }
        }
    }

    pub fn handshake(&mut self, user: &str, pass: &str, timeout: Duration) -> Result<(), ExlapError> {
        let deadline = Instant::now() + timeout;
        loop {
            match self.recv(deadline)? {
                Some(Msg::Init) => break,
                Some(_) => continue,
                None => return Err(ExlapError::Timeout("Init")),
            }
        }
        let id = self.send(r#"<Protocol version="1" returnCapabilities="true"/>"#)?;
        self.wait_rsp(id, deadline, "Protocol")?;
        let id = self.send(r#"<Authenticate phase="challenge" useHash="sha256"/>"#)?;
        let (_, children) = self.wait_rsp(id, deadline, "Challenge")?;
        let nonce = children
            .iter()
            .find(|e| e.tag == "Challenge")
            .and_then(|e| e.attr("nonce"))
            .ok_or_else(|| ExlapError::Protocol("no nonce in challenge".into()))?
            .to_string();
        let cn = auth::cnonce();
        let digest = auth::digest(user, pass, &nonce, &cn);
        let id = self.send(&format!(
            r#"<Authenticate phase="response" user="{}" cnonce="{}" digest="{}"/>"#,
            escape_attr(user),
            cn,
            digest
        ))?;
        match self.wait_rsp(id, deadline, "Authenticate")?.0 {
            None => Ok(()),
            Some(s) if s == "authenticationFailed" => Err(ExlapError::AuthFailed),
            Some(s) => Err(ExlapError::Protocol(format!("authenticate: {s}"))),
        }
    }

    pub fn subscribe(&mut self, url: &str, ival_ms: u32) -> Result<u32, ExlapError> {
        self.send(&format!(r#"<Subscribe url="{}" ival="{}" timeStamp="true"/>"#, escape_attr(url), ival_ms))
    }

    pub fn get(&mut self, url: &str) -> Result<u32, ExlapError> {
        self.send(&format!(r#"<Get url="{}"/>"#, escape_attr(url)))
    }
}
```

```rust
    pub idle_probe: Duration,
    /// Give up on the session if the probe is unanswered this long.
    pub probe_timeout: Duration,
}

impl Default for Timings {

pub struct ExlapSource {
    cfg: ExlapConfig,
    timings: Timings,
    rates: HashMap<SignalId, Rate>,
    provides: Vec<SignalId>,
}

impl ExlapSource {
    pub fn new(cfg: ExlapConfig, rates: &HashMap<SignalId, Rate>, timings: Timings) -> ExlapSource {
        let provides = map::all_signals()
            .into_iter()
            .filter(|s| rates.get(s).map(|r| r.enabled).unwrap_or(false))
            .collect();
        ExlapSource { cfg, timings, rates: rates.clone(), provides }
    }

    fn password(&self) -> Result<String, SourceError> {
        match (&self.cfg.password, auth::builtin_password(&self.cfg.user)) {
            (Some(p), _) => Ok(p.clone()),
            (None, Some(p)) => Ok(p.to_string()),
            (None, None) => Err(SourceError(format!("exlap: no password for user {}", self.cfg.user))),
        }
    }

    /// (url, ival_ms) for every URL with at least one enabled signal.
    pub fn subscriptions(&self) -> Vec<(&'static str, u32)> {
        map::urls()
            .into_iter()
            .filter_map(|url| {
                let min = map::signals_for(url)
                    .into_iter()
                    .filter(|s| self.provides.contains(s))
                    .filter_map(|s| self.rates.get(s))
                    .map(|r| r.min_interval.as_millis())
                    .min()?;
                Some((url, min.max(1000).min(u32::MAX as u128) as u32))
            })
            .collect()
    }

    fn forward(&self, dec: &mut Decoder, url: &str, fields: &[Element], tx: &Sender<Update>) -> Result<(), SourceError> {
        for (signal, value) in dec.decode(url, fields) {
            if self.provides.contains(&signal) {
                tx.send(Update { signal, value, ts: None, source: ID })
                    .map_err(|_| SourceError("router has stopped".into()))?;
            }
        }
        Ok(())
    }

    pub fn run_session<S: Read + Write>(&mut self, io: S, tx: &Sender<Update>, stop: &StopFlag) -> Result<(), SourceError> {
        let pass = self.password()?;
        let mut sess = Session::new(io);
        sess.handshake(&self.cfg.user, &pass, self.timings.handshake)?;
        info!("exlap: authenticated as {}", self.cfg.user);
        sess.send(r#"<Heartbeat ival="10"/>"#)?;
        let mut sub_ids: HashMap<u32, &'static str> = HashMap::new();
        for (url, ival) in self.subscriptions() {
            sub_ids.insert(sess.subscribe(url, ival)?, url);
        }
        let mut dec = Decoder::default();
        let mut last_rx = Instant::now();
        let mut probe: Option<(u32, Instant)> = None;
        let mut reported: HashSet<&'static str> = HashSet::new();
        loop {
            if stopped(stop) {
                return Ok(());
            }
            match sess.recv(Instant::now() + Duration::from_millis(200))? {
                Some(Msg::Dat { url, children }) => {
                    last_rx = Instant::now();
                    self.forward(&mut dec, &url, &children, tx)?;
                }
                Some(Msg::Rsp { id, status, children }) => {
                    last_rx = Instant::now();
                    if probe.map(|(p, _)| Some(p) == id).unwrap_or(false) {
                        probe = None;
                    }
                    if let (Some(s), Some(url)) = (status, id.and_then(|i| sub_ids.get(&i))) {
                        if reported.insert(url) {
                            warn!("exlap: subscription to {url} refused: {s}");
                        }
                    }
                    if let Some(url) = children.iter().find(|e| e.tag == "ObjectData").and_then(|e| e.attr("url")) {
                        let url = url.to_string();
                        self.forward(&mut dec, &url, &children, tx)?;
                    }
                }
                Some(_) => last_rx = Instant::now(),
                None => {}
            }
            let now = Instant::now();
            match probe {
                None if now.duration_since(last_rx) >= self.timings.idle_probe => {
                    probe = Some((sess.get("vehicleIdenticationNumber")?, now));
                }
                Some((_, sent)) if now.duration_since(sent) >= self.timings.probe_timeout => {
                    return Err(SourceError("exlap: liveness probe unanswered".into()));
                }
                _ => {}
            }
        }
    }

    fn connect_and_run(&mut self, tx: &Sender<Update>, stop: &StopFlag) -> Result<(), SourceError> {
        let addr = self
            .cfg
            .addr
            .to_socket_addrs()
            .map_err(|e| SourceError(format!("exlap: bad address {}: {e}", self.cfg.addr)))?
            .next()
            .ok_or_else(|| SourceError(format!("exlap: {} resolved to nothing", self.cfg.addr)))?;
        let stream = TcpStream::connect_timeout(&addr, self.timings.connect)
            .map_err(|e| SourceError(format!("exlap: connect {addr}: {e}")))?;
        stream
            .set_read_timeout(Some(Duration::from_millis(200)))
            .map_err(|e| SourceError(format!("exlap: {e}")))?;
        let _ = stream.set_nodelay(true);
        self.run_session(stream, tx, stop)
    }
}

impl Source for ExlapSource {
    fn id(&self) -> SourceId {
        ID
    }

    fn provides(&self) -> &[SignalId] {
        &self.provides
    }

    fn run(&mut self, tx: &Sender<Update>, stop: &StopFlag) -> Result<(), SourceError> {
        let result = self.connect_and_run(tx, stop);
        if result.is_err() {
            mark_unavailable(tx, ID, &self.provides);
        }
        result
    }
```

```rust
//! Thread wiring: sources -> router -> publisher.

use std::collections::HashMap;
use std::io::{Read, Write};
use std::net::{TcpListener, TcpStream};
use std::sync::atomic::Ordering;
use std::sync::mpsc::{self, RecvTimeoutError};
use std::thread::{self, JoinHandle};
use std::time::{Duration, Instant};

use crate::config::Config;
use crate::discovery::DeviceInfo;
use crate::publisher::{Publisher, PublisherConfig, TcpConnector};
use crate::router::Router;
use crate::sources::exlap::{ExlapConfig, ExlapSource, Timings};
use crate::sources::{stop_flag, supervise, StopFlag};
use crate::value::{SignalId, Update, Value};

pub struct Pipeline {
    stop: StopFlag,
    sources: Vec<JoinHandle<()>>,
    router: JoinHandle<()>,
    publisher: JoinHandle<()>,
}

impl Pipeline {
    /// Stop sources, let router and publisher drain, publish `offline`, join all.
    pub fn shutdown(self) {
        self.stop.store(true, Ordering::Relaxed);
        for h in self.sources {
            let _ = h.join();
        }
        let _ = self.router.join();
        let _ = self.publisher.join();
    }

    /// Block for the life of the daemon.
    pub fn wait(self) {
        let _ = self.publisher.join();
    }
}

pub fn publisher_config(cfg: &Config) -> PublisherConfig {
    PublisherConfig {
        topic_prefix: cfg.mqtt.topic_prefix.clone(),
        discovery_prefix: cfg.mqtt.discovery_prefix.clone(),
        device: DeviceInfo { name: cfg.device.name.clone(), model: cfg.device.model.clone() },
        vin_override: cfg.device.vin.clone(),
        client_id: cfg.mqtt.client_id.clone(),
        username: cfg.mqtt.username.clone(),
        password: cfg.mqtt.password.clone(),
        keepalive: Duration::from_secs(cfg.mqtt.keepalive_s),
    }
}

pub fn start(cfg: &Config) -> Result<Pipeline, String> {
    let rates = cfg.effective_rates();
    let stop = stop_flag();
    let (utx, urx) = mpsc::channel::<Update>();
    let (ptx, prx) = mpsc::channel::<(SignalId, Value)>();
    let mut priorities = HashMap::new();
    let mut sources = Vec::new();

    let ex = &cfg.sources.exlap;
    if ex.enabled {
        priorities.insert("exlap", ex.priority);
        let src = ExlapSource::new(
            ExlapConfig { addr: ex.addr.clone(), user: ex.user.clone(), password: ex.password.clone() },
            &rates,
            Timings::default(),
        );
        sources.push(supervise(Box::new(src), utx.clone(), stop.clone()));
    }
    drop(utx);
    if sources.is_empty() {
        return Err("no data sources are enabled".into());
    }

    let mut router = Router::new(rates, priorities);
    let router_h = thread::Builder::new()
        .name("router".into())
        .spawn(move || loop {
            match urx.recv_timeout(Duration::from_millis(250)) {
                Ok(u) => {
                    if let Some(out) = router.ingest(u, Instant::now()) {
                        if ptx.send(out).is_err() {
                            return;
                        }
                    }
                }
                Err(RecvTimeoutError::Timeout) => {}
                Err(RecvTimeoutError::Disconnected) => return,
            }
            for out in router.tick(Instant::now()) {
                if ptx.send(out).is_err() {
                    return;
                }
            }
        })
        .map_err(|e| e.to_string())?;

    let publisher = Publisher::new(publisher_config(cfg), TcpConnector { host: cfg.mqtt.host.clone(), port: cfg.mqtt.port });
    let pub_h = thread::Builder::new()
        .name("publisher".into())
        .spawn(move || publisher.run(prx))
        .map_err(|e| e.to_string())?;

    Ok(Pipeline { stop, sources, router: router_h, publisher: pub_h })
}
```

```rust
fn mosquitto() -> Option<PathBuf> {
    if let Ok(p) = std::env::var("MOSQUITTO") {
        return Some(PathBuf::from(p));

    ["/opt/homebrew/sbin/mosquitto", "/usr/local/sbin/mosquitto", "/usr/sbin/mosquitto", "/usr/bin/mosquitto"]
        .iter()
        .map(PathBuf::from)
        .find(|p| p.exists())

struct Broker(Child);

impl Drop for Broker {
    fn drop(&mut self) {
        let _ = self.0.kill();
        let _ = self.0.wait();
    }
}

fn free_port() -> u16 {
    TcpListener::bind("127.0.0.1:0").unwrap().local_addr().unwrap().port()
}

fn subscriber(port: u16) -> Client<TcpStream> {
    let s = TcpStream::connect(("127.0.0.1", port)).unwrap();
    s.set_read_timeout(Some(Duration::from_millis(50))).unwrap();
    let opts = Options { client_id: format!("e2e-{}", std::process::id()), username: None, password: None, keepalive: Duration::from_secs(30), will: None };
    let mut c = Client::connect(s, &opts, Duration::from_secs(5)).unwrap();
    c.subscribe("#", 0).unwrap();
    c
}

fn gather(c: &mut Client<TcpStream>, seen: &mut HashMap<String, String>, done: impl Fn(&HashMap<String, String>) -> bool) {
    let deadline = Instant::now() + Duration::from_secs(15);
    while Instant::now() < deadline && !done(seen) {
        for Incoming::Publish { topic, payload } in c.poll(Instant::now()).unwrap() {
            seen.insert(topic, String::from_utf8_lossy(&payload).into_owned());
        }
    }
}
```

```sh
#!/bin/sh
# carmqtt control script for the MHI2q head unit.
#
#   carmqtt.sh start | stop | restart | status | log
#
# The unit has no dirname, tail, nohup or date; ksh predefines aliases such
# as stop='kill -STOP', so every function here is prefixed with cm_.
# Persistent storage can't exec binaries, so the binary is copied to /tmp
# (RAM) and run from there. A closed ssh session sends SIGHUP, so the
# restart loop ignores it.
case $0 in */*) here=${0%/*} ;; *) here=. ;; esac
DIR=${CM_DIR:-$(cd "$here" && pwd)}
RUN=${CM_RUN:-/tmp/carmqtt}
LOOPPID=$RUN/loop.pid
PID=$RUN/carmqtt.pid

cm_running() {
    [ -f "$LOOPPID" ] && kill -0 "$(cat "$LOOPPID")" 2>/dev/null
}

cm_loop() {
    while :; do
        "$RUN/carmqtt" --config "$DIR/carmqtt.toml" &
        echo $! > "$PID"
        wait $!
        echo "carmqtt exited with status $?; restarting in 10s"
        sleep 10
    done
}

cm_start() {
    if cm_running; then
        echo "carmqtt already running (loop pid $(cat "$LOOPPID"))"
        return 0
    fi
    mkdir -p "$RUN" || return 1
    cp "$DIR/carmqtt" "$RUN/carmqtt" || return 1
    chmod 755 "$RUN/carmqtt"
    ( trap '' HUP; cm_loop ) </dev/null >>"$RUN/wrapper.log" 2>&1 &
    echo $! > "$LOOPPID"
    echo "carmqtt started (loop pid $!), log $RUN/carmqtt.log"
}

cm_stop() {
    if ! cm_running; then
        echo "carmqtt not running"
        rm -f "$LOOPPID" "$PID"
        return 0
    fi
    kill "$(cat "$LOOPPID")" 2>/dev/null
    [ -f "$PID" ] && kill "$(cat "$PID")" 2>/dev/null
    rm -f "$LOOPPID" "$PID"
    echo "carmqtt stopped"
}

cm_status() {
    if cm_running; then
        echo "carmqtt running (loop pid $(cat "$LOOPPID"), daemon pid $(cat "$PID" 2>/dev/null))"
    else
        echo "carmqtt not running"
        return 1
    fi
}

case $1 in
    start) cm_start ;;
    stop) cm_stop ;;
    restart) cm_stop; cm_start ;;
    status) cm_status ;;
    log) cat "$RUN/carmqtt.log" ;;
    *) echo "usage: $0 start|stop|restart|status|log" >&2; exit 2 ;;
esac
```

```python
#!/usr/bin/env python3
"""Add or remove the carmqtt autostart line in the unit's startup.sh.

usage: add_hook.py add|remove IN OUT

The hook goes right after the tailscale hook if present, otherwise right
after the `inetd` line in start_late_drivers(). Both are best effort:
detached, no stdio, so a missing or failing carmqtt never affects boot.
"""
import sys

MARKER = "/mnt/app/root/carmqtt/carmqtt.sh"
HOOK = [
    "    ## carmqtt autostart. Best effort only: detached, no stdio.\n",
    "    ( sleep 45; [ -x /mnt/app/root/carmqtt/carmqtt.sh ] && /mnt/app/root/carmqtt/carmqtt.sh start ) </dev/null >/dev/null 2>&1 &\n",
]


def add(text: str) -> str:
    if MARKER in text:
        return text
    lines = text.splitlines(keepends=True)
    anchor = None
    for i, line in enumerate(lines):
        if "/mnt/app/root/tailscale/tailscale.sh start" in line:
            anchor = i
    if anchor is None:
        for i, line in enumerate(lines):
            if line.strip().startswith("inetd") and "/dev/null" in line:
                anchor = i
                break
    if anchor is None:
        raise ValueError("no tailscale hook or inetd line to anchor on")
    return "".join(lines[: anchor + 1] + HOOK + lines[anchor + 1 :])


def remove(text: str) -> str:
    return "".join(l for l in text.splitlines(keepends=True) if l not in HOOK)


def main() -> int:
    if len(sys.argv) != 4 or sys.argv[1] not in ("add", "remove"):
        print(__doc__, file=sys.stderr)
        return 2
    with open(sys.argv[2]) as f:
        text = f.read()
    out = add(text) if sys.argv[1] == "add" else remove(text)
    with open(sys.argv[3], "w") as f:
        f.write(out)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# carmqtt

Publishes the status of an Audi with a MIB2 High head unit (MU1316 / MHI2Q,
QNX 6.5) to Home Assistant over MQTT, from a daemon running on the head unit
itself.

v1 reads the unit's own ExLAP server (`127.0.0.1:25010`). It needs FeCs
`00060100` (vehicle data) and optionally `00060A00` (high-performance data)
in the unit's FeC container; without them ExLAP only exposes navigation.
Door, tyre, temperature and battery data are not exposed by ExLAP on the
development car (`EC_01, not existing`) and show as unavailable until another
source provides them.

Design: `docs/superpowers/specs/2026-09-25-carmqtt-design.md`.

## Build and test

```sh
cargo test                  # host; the end-to-end test uses mosquitto if installed
scripts/build.sh            # cross-build in the qnx65-armv7-toolchain:8.5-rust image
```

```sh
cp deploy/carmqtt.toml.example deploy/carmqtt.toml   # fill in [mqtt]
deploy/install.sh audi                               # files + boot hook (backs up startup.sh)

ssh audi /mnt/app/root/carmqtt/carmqtt.sh log
```

## MQTT layout

| Topic | Payload |
|---|---|
| `mib2q/<vin>/status` | `online` / `offline` (last will) |
| `mib2q/<vin>/state/<signal/path>` | value, e.g. `69760`, `ON`, `position_P` |
| `mib2q/<vin>/avail/<signal/path>` | `online` / `offline` per signal |
| `mib2q/<vin>/location` | JSON for the device tracker |
| `homeassistant/<component>/mib2q_<vin>/<signal_id>/config` | discovery |

All retained, QoS 1. Signal ids and default rates are in `src/catalog.rs`;
per-signal overrides go in `[signals]` in the config.

## Adding a data source

Implement `sources::Source` (see `src/sources/exlap/`), map your data onto
catalog signal ids, add a `[sources.<name>]` config section, and start it in
`app::start`. The router merges sources by `priority`.
````

This task is **not** for an implementer subagent: it needs the Docker toolchain, ssh to the car, broker credentials, and the user's go-ahead for boot-file changes. The controller runs it with the user.

**Prerequisites to confirm with the user:**
- Docker Desktop can run the amd64 Rust toolchain (as of 2026-09-25 `rustc` segfaults under Docker's QEMU emulation; enabling *Use Rosetta for x86_64/amd64 emulation* in Docker Desktop fixes that), then `../qnx65-armv7-toolchain/host-scripts/qnx-run.sh build 8.5-rust` succeeds.
- MQTT broker host/port/credentials reachable from the car's tailnet node.
- The car is on and reachable as `ssh audi`.

- [ ] **Step 1: Cross-build** — `scripts/build.sh`; confirm `file target/armv7-unknown-nto-qnx650/release/carmqtt` reports `ELF 32-bit LSB executable, ARM, EABI5 ... interpreter /usr/lib/ldqnx.so.2`.
- [ ] **Step 2: On-target self-test** — `scp` the binary to `audi:/tmp/carmqtt-test` and run `ssh audi /tmp/carmqtt-test --self-test`. Expected `SELFTEST OK`.
- [ ] **Step 3: Manual run against the broker** — write `deploy/carmqtt.toml` (git-ignored) with the user's broker; copy to `/tmp/carmqtt.toml` on the unit with `[log] file = "-"`; run `ssh audi '/tmp/carmqtt-test --config /tmp/carmqtt.toml'` for ~60 s. Watch with `mosquitto_sub -h <broker> -t 'mib2q/#' -v`. Compare with the 2026-09-25 sweep: odometer, fuel %, oil, service, ignition, gear.
- [ ] **Step 4: Check the assumed unit** — note `mib2q/<vin>/state/transmission/oil_temp` right after a cold start (≈ ambient) vs. after driving; if it tracks °F rather than °C, change `fx("gearboxOilTemperature", ..., Unit::DegC)` in `src/sources/exlap/map.rs` and the catalog default, with a test, and rebuild.
- [ ] **Step 5: Confirm in Home Assistant** — the device appears with its entities; unavailable ones (doors, tyres, temperatures, location) show as unavailable.
- [ ] **Step 6: Install with the boot hook (user go-ahead required)** — `deploy/install.sh audi`; then reboot the unit (user) and confirm `ssh audi /mnt/app/root/carmqtt/carmqtt.sh status` and fresh values in HA.
- [ ] **Step 7: Record** — update the memory note `mib2-vehicle-data-taps.md` with the deployed state; commit any fixes.
